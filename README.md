# Building Measure

A single-file web page for measuring a building from a satellite map. Type an address and it outlines the building, then shows front-to-back depth, side-to-side width, every wall's length and side, corner angles, area and perimeter. You can adjust or draw the outline, measure any other distance, compare against plan dimensions, and copy, download (CSV) or print the results.

**Use it:** open `building-measure.html` in a browser (needs an internet connection), or use the hosted version on GitHub Pages.

- Free satellite imagery (Esri) by default; paste a Google Maps API key in "How it works" to use Google imagery and address search.
- Building outlines and streets come from OpenStreetMap (Nominatim and Overpass).
- Measurements are from satellite imagery, typically within 1–2 ft. Not a survey.
